force-runtime-data
==================

force-runtime-data prints information about the FORCE runtime data installation.
This includes the installation path, available sensors and their band names, as well as available indices and their required bands. 


Usage
^^^^^

.. code-block:: bash

    Usage: force-runtime-data [-h] [-v] [-i] [-p] [-s] [-x]

    -h  = show this help
    -v  = show version
    -i  = show program's purpose

    -p  = print path of FORCE runtime-data
    -s  = print sensor definitions
    -x  = print index definitions
